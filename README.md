# Codex de la Garde — Estemarche

Barème des sanctions, générateur de rapport, dossier d'interpellation, recueil des lois
(Grand Codex d'Estemarche, Fiche de poche du garde) et Mur des croquis de la Garde de Vendeaume.

## Mise en ligne sur GitHub Pages
1. Créez un dépôt **public** et envoyez-y le contenu de ce dossier (index.html à la racine).
2. Settings > Pages > Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
3. Le site est disponible à l'adresse `https://<pseudo>.github.io/<depot>/`.

## Mur des croquis
Envoyez vos images dans le dossier `Mur des croquis/` du dépôt (Add file > Upload files).
Elles apparaissent automatiquement dans l'onglet, sans script : le site lit le contenu
du dossier via l'API publique de GitHub. Les sous-dossiers deviennent des rubriques.

Avec un nom de domaine personnalisé, indiquez le pseudo et le dépôt dans `config.js`.
